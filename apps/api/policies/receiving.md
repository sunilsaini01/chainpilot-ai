# Receiving goods policy

> SIMULATED COMPANY POLICY, written for the ChainPilot demo. It is not the policy of any real company.

Version 1, 2026-10-17.

## Receiving a purchase order

A manager receives a purchase order when the goods arrive. Every line of the order is booked into stock in one step, with the order number as reference, so the stock ledger shows where each unit came from. An order can be received only once.

## Warehouse capacity

A delivery that does not fit into the warehouse is not booked at all: the whole receipt is refused and the order stays open until space is made. Partial receipts are not supported.

## Discrepancies

If the delivered quantity differs from the order, the order is received as ordered and the difference is corrected with a stock adjustment by a manager, with a reference explaining why.
